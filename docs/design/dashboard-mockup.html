8 · Reference

Provenance, panel by panel

The same ledger the design document carries, as a lookup. The minimum new recording is one table, run_events, fed by a logging.Handler on the digest logger: every WARNING and ERROR is captured with no code change; six existing log calls gain an extra= for feeds, calls, grounding and stage boundaries. Plus two wiring fixes: every run writes runs (with a dry column, and finish_run in a finally), and the UI installs the log handlers it currently never installs.
